# Contributing to SuperICP

SuperICP is a community craft project. Better questions make better ICPs for
everyone — so contributions that sharpen the interview, broaden the examples, or
make the skill usable in more contexts are all welcome.

## Ways to contribute

- **🧠 Sharper interview questions.** If you know a question a great GTM strategist
  asks that SuperICP doesn't, propose it. Tell us *which step* it belongs in
  (Step 0–8 / the AVATAR beat) and *why* it pulls out a sharper answer.
- **🏭 Industry packs.** Tailored question sets or example ICPs for a specific
  vertical (SaaS, e-commerce, nonprofit, agency, local services, creators…).
- **📝 New worked examples.** A complete `examples/` ICP for a business model we
  don't cover yet. **Examples must be fictional** — do not submit a real client's
  data. Match the structure of [`examples/example-icp.md`](./examples/example-icp.md).
- **🌍 Translations.** Of `SKILL.md`, the templates, or the README.
- **🐛 Fixes.** Typos, broken links, framework inaccuracies, contradictions.

## Ground rules

1. **Keep it evidence-first.** SuperICP's whole point is reverse-engineering an ICP
   from real customers and tagging guesses `[ASSUMPTION → validate]`. Contributions
   should reinforce that discipline, not dilute it.
2. **No proprietary or client data.** Examples are fictional. Don't paste real
   companies, real customers, or anything under NDA.
3. **Stay agent-agnostic.** SuperICP must work in any capable LLM — don't add
   tool-, model-, or vendor-specific instructions to `SKILL.md`.
4. **Match the voice.** Warm, sharp, concise — a strategist, not a chatbot.

## How to submit

- **Small fix** (typo, link, wording): open a PR directly.
- **New question, example, or industry pack:** open an issue first using a
  template so we can align on scope, then PR.

If SuperICP helped you, the best contribution is a ⭐ and sharing it with one other
marketer.
